# Input files

This folder mirrors the repo's own directory layout: each file here lives at the
same relative path as its source, under the analysis folder that actually
generated/consumes it. That means `input_files/<path>/foo` is the input used by
whatever script lives at `<path>/foo` (or is documented below), so the scripts
in this repo are reproducible by pointing them at this folder.

## Runnable copies of the scripts

Each of the 7 scripts (9 files, since 2 are `.sh`+`.R` pairs) has a copy sitting
next to its inputs in this folder. The copies are byte-identical to the
originals elsewhere in the repo **except** for a handful of path fixes needed
because the originals either hardcode a stale path (from before a folder
rename) or a path relative to this specific machine's absolute filesystem
location. Nothing else was changed — same logic, same output filenames.

Run each from inside its own folder:

```
# 08 heatmap pair (needs deepTools: computeMatrix, plotHeatmap)
cd 08_TKO_POLII_INO80_Singh_et_al/additional_analysis/heatmap/new_heatmap_TES
bash 01_TES_nuc_regSorted_orientation.sh
Rscript make_heatmap_red_blue.R

cd ../heatmap_TSS
bash 01_TSS_nuc_regSorted_orientation.sh
Rscript make_heatmap_TSS_red_blue.R

# 08 TES special comparison (parent, all genes)
cd 08_TKO_POLII_INO80_Singh_et_al/additional_analysis/TES
Rscript make_special_comparison_plots.R TES_out_profile.tab special_comparison_plots/

# 08 TES only_genes_over_1kbp (convergent / tandem)
cd 08_TKO_POLII_INO80_Singh_et_al/additional_analysis/TES/only_genes_over_1kbp/convergent
Rscript make_special_comparison_plots.R ../../TES_out_matrix.gz special_comparison_plots/

cd ../tandem
Rscript make_special_comparison_plots.R ../../TES_out_matrix.gz special_comparison_plots/

# 09 plus1_nucleosome (with optional 08 cross-dataset arg)
cd 09_TKO_INO80_WT_Singh_et_al/additional_analysis/plus1_nucleosome
Rscript make_special_comparison_plots.R TSS_out_profile.tab special_comparison_plots/ \
  ../../../../08_TKO_POLII_INO80_Singh_et_al/additional_analysis/plus1_nucleosome/plus1_out_profile.tab

# 09 TES (with optional 08 cross-dataset arg)
cd 09_TKO_INO80_WT_Singh_et_al/additional_analysis/TES
Rscript make_special_comparison_plots.R TES_out_profile.tab special_comparison_plots/ \
  ../../../../08_TKO_POLII_INO80_Singh_et_al/additional_analysis/TES/TES_out_profile.tab
```

### What was changed and why

| File | Line changed | Why |
|---|---|---|
| `heatmap/new_heatmap_TES/01_TES_nuc_regSorted_orientation.sh` | `bwChen=...` | Was hardcoded to `.../08_tko_polII/INSPECTOR_out/...`, a path that no longer exists (folder was renamed to `08_TKO_POLII_INO80_Singh_et_al`). Changed to a path relative to the script's own `$AnalysisDir`. |
| `heatmap/heatmap_TSS/01_TSS_nuc_regSorted_orientation.sh` | `Anno=...`, `bwChen=...` | Same stale-path issue, plus `Anno` pointed at the old absolute location of this same folder. Changed `Anno` to `$AnalysisDir` (matching the sibling TES script's style) and `bwChen` the same way as above. |
| `TES/only_genes_over_1kbp/{convergent,tandem}/make_special_comparison_plots.R` | `gtf_file <- ...` | Was hardcoded to the absolute path `/media/linuxmac/Storage2/scripts/08_TKO_POLII_INO80_Singh_et_al/data/genes_sacCer3.gtf` — correct on the original machine, but not portable to a GitHub clone elsewhere. Changed to a relative path pointing at the `genes_sacCer3.gtf` copy in this folder. |

All other scripts (`make_heatmap_red_blue.R`, `make_heatmap_TSS_red_blue.R`, the parent `TES/make_special_comparison_plots.R`, and both 09 `make_special_comparison_plots.R` scripts) take their inputs purely as relative paths or command-line arguments already, so they needed no changes — just correct invocation, shown above.

## INSPECTOR_out/RUN/01_BIGWIG_PROFILES
MNase-seq bigwigs used by both `.sh` scripts above (`computeMatrix -S`).

## additional_analysis/TES/TES_out_profile.tab
Input (`args[1]`) to `08_TKO_POLII_INO80_Singh_et_al/additional_analysis/TES/make_special_comparison_plots.R`.
Produced upstream by `run_tss_profile.sh` via `computeMatrix reference-point --referencePoint TES` (±1500bp, 10bp bins) + `plotProfile --outFileNameData`, run on `TES_nuc_regSorted.bed` and the same 10 bigwigs in `INSPECTOR_out/RUN/01_BIGWIG_PROFILES/` used by the heatmap scripts above (see `run_tss_profile.sh` usage comment). Not re-included separately since it's the same bigwig set.
Also reused as the cross-dataset file (`args[3]`) by `09_TKO_INO80_WT_Singh_et_al/additional_analysis/TES/make_special_comparison_plots.R`.

## additional_analysis/TES/only_genes_over_1kbp/tandem/TES_regSorted_tandem.bed
Orientation filter BED for the respective script above (read via a bare relative filename in the script, so it must sit in the working directory — it does here).

## data/genes_sacCer3.gtf
Gene-length filter (>1000bp) used by both `only_genes_over_1kbp/convergent` and `.../tandem` scripts above. The original scripts hardcode an absolute path to this file; the copies in this folder (see "Runnable copies" above) use a relative path instead so they work from a GitHub clone at any location.

## additional_analysis/plus1_nucleosome/plus1_out_profile.tab (08)
Cross-dataset file (`args[3]`) for `09_TKO_INO80_WT_Singh_et_al/additional_analysis/plus1_nucleosome/make_special_comparison_plots.R` — supplies the `TKO_Rpb1_Ino80_Rapamycin_120_min_Rep_1` condition for its optional Plot 3. Generated the same way as the 08 TES `.tab` above, from the same 08 bigwigs, but with `--referencePoint TSS`.

## 09_TKO_INO80_WT_Singh_et_al/additional_analysis/plus1_nucleosome/TSS_out_profile.tab
## 09_TKO_INO80_WT_Singh_et_al/additional_analysis/TES/TES_out_profile.tab
Inputs (`args[1]`, this experiment's own data) to the respective `make_special_comparison_plots.R` scripts. The cross-dataset `args[3]` files for these are the 08 `.tab` files listed above.

Both were generated by their local `run_tss_profile.sh` from `TSS_nuc_regSorted.bed`/`TES_nuc_regSorted.bed` + bigwigs — but for the **09 dataset** these bigwigs come from a *different* pipeline output than 08 (`PROFILER_out/RUN/01_NUCLEOSOME_PROFILE/*_monoNucs_profile.bw`, not `INSPECTOR_out`; the usage comment in the 09 TES `run_tss_profile.sh` mistakenly still says `INSPECTOR_out` — copy-paste leftover from the 08 script). See `09_TKO_INO80_WT_Singh_et_al/PROFILER_out/RUN/01_NUCLEOSOME_PROFILE/` below.

## 09_TKO_INO80_WT_Singh_et_al/PROFILER_out/RUN/01_NUCLEOSOME_PROFILE
The 8 MNase-seq bigwigs (WT, TKO, TKO+Ino80 rapamycin 90min, WT+Ino80 rapamycin 90min; reps 1/2) that `run_tss_profile.sh` used to generate the 09 `TES_out_matrix.gz`/`TES_out_profile.tab` and `TSS_out_profile.tab` above. Included so those files are regeneratable from raw signal, not just reusable as precomputed.

## Note on the sacCer3 genome FASTA
`data/genome_sacCer3.fa` exists alongside `genes_sacCer3.gtf` in both the 08 and 09 repos, but none of the 7 scripts covered here read it — only the GTF *annotation* (gene coordinates) is used, for the >1000bp length filter. It is intentionally **not** included here.
